## Project Overview 
CashLens is a business management solution built using Odoo. It helps small and medium  businesses manage customers, sales orders,invoices,payments and cashflow all in one platform.

## Problem
Many businesses rely on spreadsheets to track sales and payments. This can lead to errors, delays, and difficulty monitoring cash flow.

## Solution
CashLens uses Odoo to automate sales and accounting processes. It allows businesses to create quotations, convert them into sales orders, generate invoices, record payments, and track revenue efficiently.

## Features
- Customer Management
- Sales Order Processing
- Invoice Generation
- Payment Tracking
- Revenue Monitoring
- Business Reporting

## Tools Used
- Odoo
- Microsoft Excel
- Microsoft PowerPoint
- GitHub

## Demo Workflow
Excel Data → Customer Records → Sales Orders → Invoices → Payments → Reports
